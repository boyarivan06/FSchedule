# Проект F-Schedule (WIP)
## Приложение для семейного расписания
___
### Идея
Практически все большие семьи используют для создания расписания обычные приложения наподобие Google Calendar или, того хуже, делают его в Excel. Данный проект призван упростить работу многодетным матерям и всем, исполняющим сходные функции. Функционал позволит как организовывать общее расписание большой семьи, так и вести личное каждому из её членов.
___
### Планирующийся функционал
1. Добавление детей и взрослых в семейную группу (со специальными аккаунтами) 
2. Добавление события (урока, кружка, повторяющегося или нет) в расписание конкретного ребёнка
3. Система будет формировать расписание в интерфейсе, файлы pdf и ics
4. Каждому событию в расписании ребёнка будет при необходимости присваиваться свободный в это время взрослый, который будет отвозить и забирать ребёнка
___
